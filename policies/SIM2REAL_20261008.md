All four were distilled from scratch with symmetry in Newton mesh. Each directory contains the CPU TorchScript `policy.pt` and its matching `contract.json`; normalization is included in the exported policy. The input is 690 proprioceptive values plus a 3×38×64 depth stack, with 43 policy action slots mapped to 29 robot motors. Control period: 20 ms.

Use the existing deployment command with the selected directory, for example:

```text
--depth policies/height35-student-s43-i16000 --policy_physics g1_29dof
```

Use the same selected `--depth` directory for `scripts/run_sim_loop.py` when rehearsing in MuJoCo. The original Linux checkpoint path in the contract is provenance; it is not needed to run the policy on Mac. Hardware results are pending; these are candidates, not hardware-validated policies.

After pulling this commit on Mac, verify the files:

```bash
python - <<'PYVERIFY'
import hashlib, json
from pathlib import Path
manifest = json.loads(Path("policies/sim2real_20261008_manifest.json").read_text())
for model in manifest["models"]:
    root = Path(model["directory"])
    for name, key in [("policy.pt", "policy_sha256"), ("contract.json", "contract_sha256")]:
        assert hashlib.sha256((root / name).read_bytes()).hexdigest() == model[key], root / name
    print("OK", model["order"], model["name"])
PYVERIFY
```
