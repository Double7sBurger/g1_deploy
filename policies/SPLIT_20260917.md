Workflow: `g1-split-walk-1`. All six policies finished training. These exports have
been checked against their original model on CPU (maximum absolute difference 0)
and loaded through the existing `g1_deploy` policy loaders. This is an export check,
not a completed MuJoCo gait benchmark or hardware test.

All trained on Newton (`newton_mjwarp`). The blind tasks used no terrain generator,
height scanner, or height-scan observation. Every rough sub-terrain in the visual
teacher and student had `convert_to_heightfield=false`. This describes the training
collider; the Mac MuJoCo collider is determined by the selected XML scene.

Every policy directory contains:

- `policy.pt`: portable CPU TorchScript used by the existing Mac runners.
- `contract.json`: joint order, nominal gains/default pose, action scale, observation
  layout, camera geometry where applicable, and checkpoint provenance/checksums.
- `checkpoint.pt`: unmodified original training checkpoint, for archival/re-export.
- `training/params/{env,agent}.yaml`: exact resolved training configuration.

The three privileged teacher checkpoints are archived separately under
`ckpt/split_20260917/teacher_s{42,43,44}/`; they are not directly deployable.
The manifest is `policies/split_20260917_manifest.json`.

## Blind policy — Mac, two terminals

Run from the `g1_deploy` checkout, in the existing deployment environment.
The examples use the default flat scene and the training plate-foot geometry.

Terminal 1:

```bash
mjpython scripts/run_sim_loop.py --viz --foot_plate --policy_physics g1_29dof \
  --domain_id 71 --interface lo0 --hoist_s 4
```

Terminal 2:

```bash
python scripts/run_policy_loop.py --real --skip_release_mode \
  --policy policies/blind_s42 --policy_physics g1_29dof \
  --vx 0.5 --vy 0 --duration 20 --ramp_s 3 --domain_id 71 --interface lo0
```

Swap `blind_s42` for `blind_s43` or `blind_s44` to compare seeds.
`--real --skip_release_mode` is the existing DDS control path against the simulator
in terminal 1; domain 71 separates this test from the robot's domain 0.

## Depth policy — Mac, two terminals

Stop the previous two processes before switching policies.

Terminal 1:

```bash
mjpython scripts/run_sim_loop.py --viz --foot_plate --policy_physics g1_29dof \
  --depth policies/tracking_depth_s43 \
  --domain_id 72 --interface lo0 --hoist_s 4
```

Terminal 2:

```bash
python scripts/run_policy_loop.py --real --skip_release_mode \
  --depth policies/tracking_depth_s43 --policy_physics g1_29dof \
  --vx 0.5 --vy 0 --duration 20 --ramp_s 3 --domain_id 72 --interface lo0
```

Use the same depth-policy directory in both terminals. Swap seed 43 for 42 or 44
in both commands to compare seeds. To test an existing rough MuJoCo scene, pass its
path with `--xml` to terminal 1.

Blind action scale is 0.5; visual policies use the YMS per-joint action scales.
Pass the policy directory as shown so the runner reads its contract. The depth
contract uses the nominal calibrated camera pose; the ±5 degree pitch variation
was training domain randomization, not a fixed additional tilt for deployment.
